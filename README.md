# Dipen AI Platform (DAP)

> **Local-first AI. Cloud when you choose.**

Dipen AI Platform (DAP) is a modular, self-hosted AI operating platform designed for software development, learning, research, and personal productivity.

DAP combines local Large Language Models (LLMs), personal knowledge bases, optional cloud AI providers, and intelligent routing into a single privacy-first platform.

---

## Vision

DAP is built around one simple philosophy:

> **AI should earn your trust, not assume it.**

Every answer should explain:

- Which model generated it
- Which knowledge source was used
- Whether the internet was used
- Whether cloud AI was involved
- Why the answer should be trusted
